# AI Transparency

This experimental build and its documentation were prepared with substantial assistance from OpenAI Codex/ChatGPT.

Human role:

- Reported and described the GT6 mirror bugs.
- Ran the game tests on local hardware.
- Compared patched and unpatched RPCS3 builds.
- Checked additional games, including GT5 Prologue and Need for Speed Shift.
- Approved publication as an experimental public test build.

AI assistant role:

- Helped inspect RPCS3 source code and local logs.
- Proposed and iterated the experimental RSX texture-cache changes.
- Built local test executables.
- Prepared the patch, packaging notes, release text, and this repository structure.

Important caveat:

This is not an official RPCS3 change and not an upstream-ready pull request. The AI-assisted code should be reviewed like any other experimental patch, with special attention to correctness, blast radius, and title-specific assumptions.
